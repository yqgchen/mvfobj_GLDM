# GLDM: Geodesic Latent Deformation Model

Code for the simulation studies and data application in the paper.

## Requirements

- R 4.4.0
- R packages: frechet (0.3.0), fdasrvf (2.4.4), pracma (2.4.6), minqa (1.2.8), Matrix (1.7.5), expm (1.0.0), SMFilter (1.0.3), osqp (0.6.3.2), rgl, corrplot
- Application additionally requires: fdadensity (0.1.2), fdapace (0.6.0), OPW (0.1.0, installed from GitHub)

## File Overview

- `simulation/`: Simulation studies
  - `make_plots.R` Generates boxplot summaries. Set `data_type` ("spd" or "nw") and `scenario` ("bothvar" or "phaseonly") at the top. Also provides `plot_tau_spd()` and `plot_tau_nw()` for visualizing the true template trajectory.
  - `results/`: Simulation result rds files.
  - `figures/`: Boxplot PDFs (generated by make_plots.R).
  - `spd/`: SPD matrix simulations (Case 1)
    - `analyze_data.R` Main script for running the simulation locally.
    - `simulate_data.R` Data generation (joint-variation setting).
    - `simulate_data_phaseonly.R` Data generation (phase-variation-only setting).
    - `fctns_estimation.R` Functions for the GLDM and CM estimation.
    - `fctns_evaluation.R` Evaluation metrics (sWMISE, gWMISEp, gWMISEr, cWMISE, TISE, and PMISE).
    - `fctns_srvf.R` Functions for SRVF methods, alignment to Karcher mean and pairwise alignment, only the latter shown in the paper as the results of the former are not sensible.
  - `lap/`: Graph Laplacian simulations (Case 2)
    - `analyze_lap.R` Main script for running the simulation locally.
    - `simulate_lap.R` Data generation (joint-variation setting).
    - `simulate_lap_phaseonly.R` Data generation (phase-variation-only setting).
    - `fctns_estimation_lap.R` Functions for the GLDM and CM estimation.
    - `fctns_evaluation.R` Evaluation metrics (sWMISE, gWMISEp, gWMISEr, cWMISE, TISE, and PMISE).
    - `fctns_srvf_lap.R` Functions for SRVF methods, alignment to Karcher mean and pairwise alignment, only the latter shown in the paper as the results of the former are not sensible.
    - `lnr.R` Local Fréchet regression for graph Laplacians. Obtained from [Zhou and Müller (2022)](https://jmlr.org/papers/v23/22-0681.html), JMLR.
  - `cluster/`: High-performance computing (HPC) cluster scripts
    - `run_cluster_spd.R` and `run_cluster_lap.R` Server execution scripts (joint-variation).
    - `run_cluster_spd_phaseonly.R` and `run_cluster_lap_phaseonly.R` Server execution scripts (phase-variation-only).
    - `submit_spd.sh` and `submit_lap.sh` SLURM submission scripts (joint-variation).
    - `submit_spd_phaseonly.sh` and `submit_lap_phaseonly.sh` SLURM submission scripts (phase-variation-only).
    - `merge_results.R` Merges per-seed CSV results into an rds file.
- `application/`: Application to mortality data
  - `analyze_data.R` Main pipeline: preprocessing, GLDM estimation, and saving results.
  - `make_plots.R` Figure generation.
  - `preprocess_hmd_txt_to_rds.R` Converts raw HMD txt files to country-level rds.
  - `fctns_preprocess.R` Preprocessing functions.
  - `fctns_estimation.R` GLDM estimation functions.
  - `data/` Raw life table txt files, downloaded on March 10, 2023 from the [Human Mortality Database](https://www.mortality.org).
  - `data_rds/` Country-level rds files (generated by scripts).
  - `results/` Estimation results (generated by scripts).
  - `figures/` Plots (generated by scripts).
  - `GDP_MPD_1988.csv` GDP per capita for 34 countries in 1988 obtained from the [Maddison Project Database](https://www.rug.nl/ggdc/historicaldevelopment/maddison/releases/maddison-project-database-2023?lang=en).


## Simulations

### Local Verification

It is not feasible to reproduce all the simulation results on a standard machine (e.g., a desktop or a laptop). For a quick verification, run the R scripts `simulation/spd/analyze_data.R` and `simulation/lap/analyze_lap.R`. By default, these run $B=2$ replicates for the joint-variation setting on a subset of noise levels. Results are saved in `simulation/results/`. To generate figures of boxplots, run `simulation/make_plots.R` with `data_type` and `scenario` set properly. For the phase-variation-only setting, replace the data simulation source and estimation function as described in the comments of the aforementioned two scripts.

### Full reproduction (HPC cluster)

The full simulation ($B=250$, 27 noise combinations, 4 methods, 2 cases and 2 settings) requires an HPC cluster. SLURM submission scripts are provided in `simulation/cluster/`.

1. Upload the code to your cluster.
2. Submit jobs: `sbatch --array=1-250 submit_spd.sh` and `sbatch --array=1-250 submit_lap.sh` (and corresponding `_phaseonly` scripts).
3. After completion, merge CSV results into rds using `merge_results.R`. Download the rds files to your local machine, place them in `simulation/results/`, and run `make_plots.R` to generate plots.

## Application (Mortality Data)

1. Run `application/analyze_data.R` to preprocess mortality data, fit the GLDM, and save results.
2. Run `application/make_plots.R` to generate figures.
